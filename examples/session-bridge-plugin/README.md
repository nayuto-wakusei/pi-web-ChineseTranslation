# 工作区审查：源码示例

推荐使用无需编译的[船长日志](../../docs/plugins.md#try-captains-log)，入口为“设置 → Pi 包 → 可用包”。本例保留为参考，不迁移旧审查记录。

本例在专用 Pi 会话中审查工作区未提交改动，保存结果，并提供“审查”面板。它替代了旧会话桥接问候示例，默认不安装、不启用。

在独立目录运行：

```sh
npm install
npm run build
```

需要 PI WEB `^1.202609.1` 的插件数据目录和会话消息 API；原生伴随扩展基于 Pi 0.87.0 验证。尚未发布的开发版本应先安装本地构建的 PI WEB tarball，再编译本例。

在目标机器“设置 → Pi 包”安装包的绝对目录，启用“工作区审查”及其伴随扩展。在确认可中断会话后，从目标 daemon 所托管的会话之外手动重启 daemon，再刷新浏览器。仅重启 Web/API 不会激活新后端。

选择工作区，在“审查”面板点击“开始审查”，通过“刷新审查”查看进度和保存结果。选择记录或使用“上一条审查 / 下一条审查”查看纯文本结果，完整会话 ID 用于在会话列表找到对话。

使用敏感代码前阅读[安装、行为、存储与限制](docs/usage.md)。运行审查需要模型凭据；包和普通代理工具以机器用户的权限执行。
