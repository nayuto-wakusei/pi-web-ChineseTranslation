Import scope and changes:
Generated from dist/material-icons.json's default file, fileNames and
fileExtensions. Light overrides are omitted because consumers render these
shapes as monochrome CSS masks. No folder pack, executable upstream
code, language-id heuristics, or optional icon packs are imported. Path-based
fileNames are omitted because PI WEB matches basenames, not full paths.
Extension keys become dot-prefixed suffixes. Rules sharing an asset are
grouped without changing filename/extension precedence.
SVG artwork is unchanged; non-rendering metadata adds attribution to each
SVG. The default file.svg additionally embeds this notice and both complete
licenses so they survive Vite's asset-only production packaging. There is no
network/CDN dependency at runtime. No separate upstream NOTICE was present.

Regenerate with: npm run generate:material-icons
The dev:client, build, typecheck, typecheck:cached and test npm scripts generate
ignored local SVGs and the mapping automatically from installed package data.
No download or upstream executable code is involved in generation; npm checks
package integrity during installation. Vite emits individual local SVG assets.
