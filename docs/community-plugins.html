社区包

社区贡献，未经审查或背书。 插件可使用运行账号的权限执行代码，只安装可信作者的包。

按名称或描述搜索，留空可浏览全部结果。

热门排序使用过去一个月的下载量。

启用 JavaScript 后可在此搜索，也可使用下方链接直接浏览 npm。

    直接在 npm 浏览： PI WEB 插件 · 扩展插件搜索 （可能包含不相关的包）。

    安装插件
    1. 从 npm 复制包名。
    2. 在 PI WEB 中选择目标机器，打开设置 → Pi 包。
    3. 输入 npm:package-name（或 npm:@scope/package-name），选择安装。
    4. 打开设置 → PI WEB 插件，检查并按需启用集成，再遵循显示的刷新或重启提示。

    安装包与启用 Web 集成是两项独立操作，详见安装与管理。

    分享插件

    发布带有效 piWeb.plugins 声明的公开 npm 包，在 package.json 加入这些关键词：

    {
  "keywords": ["pi-web.dev-plugin", "pi-package", "pi-web-plugin"]
}

    使用 pi-web.dev-plugin 标识本项目插件，同时保留 pi-web-plugin，方便通过扩展搜索发现。

    无需向 PI WEB 注册关键词或提交插件。发布包含关键词的新版本后，发现结果取决于 npm 搜索索引，可能延迟出现。

    提供清晰的描述、仓库链接、安装说明和支持的 PI WEB 版本，便于用户判断。关键词只用于发现，不能替代插件清单。
