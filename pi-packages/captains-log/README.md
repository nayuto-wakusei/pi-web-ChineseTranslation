# 船长日志（Captain's Log）

让戏剧化的海盗船长转述选中会话最新已完成的助手回复，保留重要事实、警告和后续步骤。浏览器面板通过后端与原生 Pi 伴随扩展交互，不向源会话发送提示或修改转录。

此示例随 PI WEB 预构建分发，但**默认不安装、不启用**。使用时，在目标机器的“设置 → Pi 包 → 可用包”中安装，再到“设置 → PI WEB 插件”中显式启用。也可使用目标机器的 Pi 配置执行 `pi install /absolute/path/to/dist/pi-packages/captains-log`。

服务端入口需要从承载会话之外手动重启目标 session daemon 才能激活，随后刷新浏览器。重启可能中断正在运行的会话；现有会话还需执行 `/reload` 加载伴随扩展。

选择会话，打开工作区的“船长日志”，点击“让船长转述”。此操作使用你配置的模型，可能产生费用，源文本会发送给模型提供方。这是受信任的代理代码，不是只读沙箱。打开面板本身不会发起模型调用。详情见[使用与恢复](docs/usage.md)。

维护者：仓库根目录的 `npm run build` 在 `dist/pi-packages/captains-log/` 生成可安装副本，本示例不单独发布到 npm。
